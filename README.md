# Maria Cruz — Produção, Arte & Experiências

Prévia local do site institucional com fotografias recortadas dos nove prints do portfólio enviado. As imagens finais ficam em assets/photos, e cada projeto usa apenas fotografias correspondentes às páginas identificadas.

## Abrir a prévia local

Execute node server.cjs nesta pasta e acesse http://127.0.0.1:4173. As fotografias da galeria podem ser ampliadas ao clicar.

## Pendências antes da publicação

- Os recortes vêm dos prints 1920×1080; as fotografias internas têm entre aproximadamente 400 e 712 px de largura. Para ampliações grandes ou telas de alta densidade, solicitar os arquivos fotográficos originais à Maria.
- Confirmar textos e política de privacidade com Maria.
- Maria definirá preços, conteúdo programático, calendário e links oficiais dos cursos; os cursos permanecem como “Em preparação”, sem preços.
- A prévia é local. Nenhuma versão foi publicada em produção.

O formulário abre uma conversa no WhatsApp com os dados preenchidos e não armazena informações neste site.
